Where they genuinely differ

A is dense and instrumented: 52px monospace hero behind a red severity rail, segmented pill controls, tight 9px measure rows, luminous route with a glow filter.

B is an editorial record: 58px sans hero, small-caps ruled rows at 13px spacing, underlined text tabs, bordered form-style controls, flatter 2.8px cartography with no glow, 24px gutters against A's 18px.

Monospace, used selectively

Reserved for the hero figure in A, the comparison-table numbers, identifiers, versions and map labels. Secondary measures use the sans with tabular-nums, so columns still align without the panel reading as a terminal. B sets its hero in the sans entirely.

Honest labelling

The scope line states this is an AMDS source feature closure, not a road segment, because that is what the current engine removes. Added time is marked estimated speeds. The snapshot is identified as the reconciled pre-hardening pilot.

Figures will need regenerating once segment scope and exact restriction handling land.
